# 🐷 每日小猪 — AstrBot QQ 群聊插件

> 群友发一句 `今日小猪`，机器人随机抽一只专属小猪，合成一张**带稀有度边框的卡牌**：插画 + 名字 + 一句钩子 + 性格解析。
>
> 四档稀有度、保底、图鉴、本群排行榜、联网扩充素材，全部自带；关键词、概率、卡面文案都能在控制台里热改，不用重启。

## ⚡ 快速开始

1. **安装插件**：在 AstrBot WebUI 的插件市场搜索「每日小猪」一键安装（列表里显示为「每日小猪（抽卡）」），或把整个目录放进 `data/plugins/astrbot_plugin_meirixiaozhu/`
2. **安装依赖**：WebUI → 插件管理 → 每日小猪（抽卡） → 点「安装依赖」（`Pillow`、`requests`）
3. **直接用**：群里发一句 `今日小猪` 或 `每日小猪`

不需要 `/` 指令、不需要 @机器人、不需要任何 API Key。内置 150 只小猪，装完即可抽。

想改触发词、要求必须 @机器人、调整稀有度概率、改卡片文案，进 WebUI 的「每日小猪」控制台即可，改完即时生效。

## ✨ 功能特性

- 🎴 **稀有度卡牌**：N / R / SR / SSR 四档，边框配色、装饰强度、全息效果依次增强
- 🎲 **每日抽卡**：默认每人每天 1 次，可调；0 点自动重置
- 🔁 **次数用完也有卡**：再发一次会把今天最后抽到的那只重发一遍，并说明次数已用完，不会出现「有回话没小猪」
- 🛡️ **保底机制**：连续多次没出 SR 以上，下一次必定高稀有
- 📖 **小猪图鉴**：个人收集进度，按稀有度分组，未解锁显示占位
- 🏆 **本群排行榜**：按收集数或 SSR 数量排名，只统计当前群
- 🌐 **联网扩充**：自动从 PigHub 拉新图，并用当前模型看图写文案
- 🗝️ **关键词全可配**：抽卡 / 帮助 / 图鉴 / 排行 / 池子 / 更新素材六组触发词，都能在控制台里改
- 🔔 **艾特唤醒开关**：可要求必须 @机器人 才响应，避免群聊误触发
- ✏️ **卡片文案可改**：显示名、一句话、描述都能在控制台里改，留空即恢复原文
- 🖥️ **控制台五合一**：外观预览 / 配置 / 扩充猪池 / 存储占用 / 数据管理，全部热改
- 🔤 **缺字自动回退**：字体子集外的生僻字自动切换备用字体，不会出现方块
- 👥 **艾特查看**（可选）：`每日小猪 @某人` 看对方今天抽到的小猪
- 🛡️ **降级容错**：图片缺失、渲染失败、发送失败均自动降级为纯文本，不崩

## 🎴 卡面与稀有度

| 稀有度 | 默认占比 | 边框 | 装饰 |
|--------|:--------:|------|------|
| **N** 普通 | 45% | 石墨灰渐变 | 无 |
| **R** 稀有 | 33% | 钢蓝渐变 | 四角菱形 |
| **SR** 超稀有 | 17% | 紫罗兰渐变 | 菱形 + 边框斜纹 |
| **SSR** 传说 | 5% | 金橙渐变 | 菱形 + 斜纹 + 顶部徽记 + 彩虹全息 |

卡面 960×1200，全部由 PIL 程序化绘制，**不使用任何外部图片素材**，版式是通用集换式卡牌布局（标题条 / 插图区 / 文本框 / 页脚），与任何商业卡牌游戏无关。

两个细节：

- **占比可改**：控制台里填 N / R / SR 三个百分比，SSR 自动补足剩余，改完立即重新分级
- **分级怎么算**：内置素材按 pid 哈希稳定映射（改文案、换字体都不会变档）；运行时新扩充的小猪按当前四档的缺口分配，池子越大越贴近目标占比

## 📦 小猪素材与自动扩充

**内置 150 只**：图片取自 [PigHub](https://www.pighub.top) 公共表情包图库，本地压缩为 WebP（最大边 640px、单图 ≤180KB）；每只的一句话与性格解析均为本项目原创文案。

**自动扩充**：按 `sync_interval_hours` 从 PigHub 拉新图并生成文案，三级降级保证一定有结果：

1. **看图生成** — 当前模型能读图时，图片和写作规范一起发过去
2. **纯文本生成** — 模型不支持读图时，只给标题
3. **本地模板** — 没有可用模型，或用模板兜底

扩充出来的素材存在插件数据目录，**不计入插件体积**。也可以在控制台「扩充猪池」里手动填数量立刻拉一批，并看到这次花了多少 token、折合多少钱。

> 实测（DeepSeek Flash，看图模式）：每只约 360 输入 + 1950 输出 token，折合 **¥0.008/只**，100 只约 8 毛。输出偏高是因为推理 token 也计入 output。

## 🔧 技术实现

- **关键词判定在处理器内**：装饰器上挂 `@filter.regex(r"[\s\S]+")`，真正的匹配在 `on_trigger` 里按配置做，所以改关键词立即生效、原生配置页改也生效，且不消耗 LLM token
- **图像不落盘**：卡面渲染直接输出 `bytes`，通过 `Comp.Image.fromBytes()` 发送
- **CPU 密集转线程**：渲染走 `asyncio.to_thread()`，不阻塞事件循环
- **sqlite 账本**：单文件记录，支持按群聚合排行
- **字体子集化**：11MB → 4MB，附字符集清单做缺字回退
- **错误隔离**：图片缺失、渲染异常、发送失败均降级为纯文本

## 🙋 FAQ

**Q: 为什么不用 `/每日小猪` 指令？**

A: 群聊是自然语言场景，直接说「每日小猪」比 `/每日小猪` 更符合聊天直觉。真想要斜杠指令，把触发词改成 `/每日小猪` 就行。

**Q: 每人每天能抽几次？次数用完了会怎样？**

A: 默认 1 次，可改。用完之后再发触发词，机器人会把**你今天最后抽到的那只**重发一遍，并附一句「今日抽取次数已用完」——不会出现「有回话但没小猪」的情况。

**Q: 抽不到 SSR 怎么办？**

A: 开保底。默认连续 10 次没出 SR 以上，下一次必定高稀有，抽中后计数归零。

**Q: 自动扩充会烧很多 token 吗？**

A: 每只新猪一次模型调用，默认每轮 5 只、每天一轮，约 4 分钱。嫌多就把 `sync_batch_size` 调小，或关掉 `use_llm_persona` 改用模板，也可以整个关掉 `auto_sync`。

**Q: 猪池太大了想清理？**

A: 控制台「数据管理」里可以单只删、清空动态缓存；也可以直接删数据目录下的 `dynamic/`，会恢复成内置 150 只，不影响抽卡记录。

**Q: 卡片上的字变成方块了？**

A: 说明该字符不在子集字体里且回退失败。请在 issue 里贴出具体字符，重新子集化时补进去。

**Q: 能和 rollpig（今日小猪）一起用吗？**

A: 能，但两个都响应「今日小猪」时会各回一张卡。现在不用改代码了：把本插件的 `trigger_keywords` 改成别的词（或反过来改它），或者只启用其中一个。

**Q: 从旧版本升级会丢数据吗？**

A: 会。2.0.0 换了数据结构（JSON → sqlite），旧版的抽卡记录不会自动迁移，升级后从零开始。猪池和配置不受影响。
